# 📦 Ürün Görselleri Klasörü

Bu klasöre ürün resimlerinizi yükleyin.

## Desteklenen Formatlar
- `.png` (şeffaf arka plan için önerilir)
- `.jpg` / `.jpeg`
- `.webp`

## Dosya Adlandırma
Aşağıdaki isimleri kullanırsanız sitede otomatik görünür:

| Dosya Adı | Ürün |
|---|---|
| `protein.png` | Whey Protein |
| `creatine.png` | Kreatin |
| `pre_workout.png` | Pre-Workout |
| `bcaa.png` | BCAA |
| `multivitamin.png` | Multivitamin |
| `collagen.png` | Kollajen |
| `hero.png` | Ana sayfa büyük görsel |
| `capsule.png` | Uçan kapsül dekor görseli |

## Özel İsim Kullanmak İçin
`src/data/products.ts` dosyasını açın ve `image` alanını değiştirin.

## Önerilen Boyutlar
- Ürün görselleri: **600×600 px** (kare, şeffaf PNG)
- Hero görseli: **800×800 px**
- Minimum: 300×300 px
